# gongdan007

网站中后台统一管理，员工、投手等使用者通过长期登录码进入桌面客户端，客户端直接展示各平台官方 Web 页面。首个平台为 WhatsApp。

当前版本为 0.1.0 基础开发版：已实现中后台基础、长期登录码及平台授权与分组、单条及批量删除、代理导入与关联、代理分组和每平台额度及启停、客户端添加账号与官方 WhatsApp 二维码及 Google 免费翻译；账户中心与推广中心已接入人工充值 / 退款审核、钱包流水、推广注册返佣、佣金转余额、提现审核与免费字符日志。底库支持客户账号 / IP 导入、团队内同平台查重、对话登记与重算，客户端增加原生聊天查重浮层。自动支付、套餐购买及其余业务模块仍待开发，手机扫码后的真实聊天与长期在线尚待验收。

## 产品边界

- 网站负责管理、权限、配置、统计、客户运营和日志。
- 客户端负责本地浏览器会话、平台登录和原生网页聊天；外围提供账号切换、两步确认退登 / 移除及可折叠客户工具，包括快捷图片 / 话术、标签、客户翻译语言和资料备注。API 号码支持仅从当前客户端移除。
- 登录码可重复使用；管理后台可设置有效期、可用平台、分组、重置、停用及删除；登录码不限制设备数或账号数。每平台账号数量只按代理配置限制。
- 中后台采用 Vue Vben Admin 的 Element Plus 方案；服务端使用 Go；客户端采用 Electron。
- 平台接入先完成 WhatsApp，后续平台通过独立适配模块加入。

## 目录

```text
apps/admin/              网站中后台
apps/desktop/            Electron 客户端
server/                  Go API 与后台任务
packages/platform/       平台适配契约与 WhatsApp 适配器
packages/api-client/     根据接口契约生成的 TypeScript 客户端
packages/ui-tokens/      自有界面的样式变量
contracts/               模块、接口与事件契约
infra/                   部署与备份配置
scripts/                 本地开发和发布工具
docs/                    产品、架构与验收文档
```

业务代码、构建产物和运行数据分开保存。后续开发以阶段验收为界；每次发布必须能追溯到 Git 提交和对应数据库迁移。
