# D1 Scrm 桌面客户端下载

首发版本 0.1.0。官网提供 Windows x64 安装向导（EXE）、Mac Apple Silicon 与 Intel 安装镜像（DMG），内置服务地址 `https://api.d1scrm.com`。安装后在网站后台生成登录码，再在客户端登录。

## 构建

在 macOS 开发镜像安装仓库锁定的依赖后执行：

```sh
pnpm --filter @gongdan/desktop package mac-arm64 mac-x64 win-x64
```

需要 macOS 的 `codesign`、`hdiutil`；Windows NSIS 跨平台构建工具由 electron-builder 获取。Electron 和 electron-builder 版本在 `apps/desktop/package.json` 锁定。

产物位于 `.runtime/desktop-release/0.1.0/artifacts`。发布脚本单独构建前端和主进程，暂存包只使用应用代码，不复制本机授权、账号资料目录、环境文件或管理凭据。打包输出包括版本 / 服务地址清单 `release.json` 和 `SHA256SUMS`。

图标源文件在 `apps/desktop/resources/icon.svg`，PNG / ICNS 为对应分辨率资源。更换版本时同步更新首页下载链接和版本号，发布路径按版本隔离，不覆盖已发布版本的文件。

## 对外目录

仅把三个安装包、`release.json` 和 `SHA256SUMS` 复制到服务器 `/opt/d1scrm/client-downloads/0.1.0/`。不要发布整个 artifacts 目录，里面包含打包中间文件和未压缩应用。

两个主站通过 `/client-downloads/0.1.0/` 下载。Caddy 使用单独静态目录，强制附件响应，文件不存在返回 404；不经过网站 SPA 回退。旧 `/downloads/` 路径保持退役 410。

## 签名与验证范围

- Mac 使用 ad-hoc 签名，尚无 Apple Developer ID / 公证。Windows 未配置代码签名证书。首页安装说明如实展示该状态，不能宣称已通过系统厂商验证。
- macOS 需要 13 及以上；Windows 面向 Windows 10 / 11 x64。Intel / AMD 选择 Windows x64，苹果芯片选择 Mac arm64，Intel Mac 选择 Mac x64。
- 通过 Mac 实际启动和线上健康检查验证安装包中的应用，检查包内 API 地址及资源；Windows 包进行结构和校验验证。Windows 真机安装与业务扫码仍需实机验证。
- 暂未接入自动更新；升级时从首页重新下载。普通卸载不主动清除本机账号资料。
