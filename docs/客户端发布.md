# D1 Scrm 桌面客户端下载

当前版本 0.1.7。官网提供 Windows x64 安装向导（EXE）、Mac Apple Silicon 与 Intel 安装镜像（DMG），内置服务地址 `https://api.d1scrm.com`。安装后在网站后台生成登录码，再在客户端登录。

## 构建

在 macOS 开发镜像安装仓库锁定的依赖后执行：

```sh
pnpm --filter @gongdan/desktop package mac-arm64 mac-x64 win-x64
```

需要 macOS 的 `codesign`、`hdiutil`；Windows NSIS 跨平台构建工具由 electron-builder 获取。Electron 和 electron-builder 版本在 `apps/desktop/package.json` 锁定。

产物位于 `.runtime/desktop-release/<package.json 中的版本>/artifacts`。发布脚本单独构建前端和主进程，暂存包只使用应用代码，不复制本机授权、账号资料目录、环境文件或管理凭据。打包输出包括版本 / 服务地址清单 `release.json` 和 `SHA256SUMS`。

图标源文件在 `apps/desktop/resources/icon.svg`，PNG / ICNS 为对应分辨率资源。更换版本时同步更新首页下载链接和版本号，发布路径按版本隔离，不覆盖已发布版本的文件。

## 对外目录

仅把三个安装包、`release.json` 和 `SHA256SUMS` 复制到服务器 `/opt/d1scrm/client-downloads/0.1.7/`。不要发布整个 artifacts 目录，里面包含打包中间文件和未压缩应用。

两个主站通过 `/client-downloads/0.1.7/` 下载，0.1.0 / 0.1.1 / 0.1.2 / 0.1.3 / 0.1.4 / 0.1.5 / 0.1.6 历史安装包保留。Caddy 使用单独静态目录，强制附件响应，文件不存在返回 404；不经过网站 SPA 回退。旧 `/downloads/` 路径保持退役 410。

## 签名与验证范围

- Mac 使用 ad-hoc 签名，尚无 Apple Developer ID / 公证。Windows 未配置代码签名证书。首页安装说明如实展示该状态，不能宣称已通过系统厂商验证。
- macOS 需要 13 及以上；Windows 面向 Windows 10 / 11 x64。Intel / AMD 选择 Windows x64，苹果芯片选择 Mac arm64，Intel Mac 选择 Mac x64。
- 通过 Mac arm64 原生启动、Mac x64 在 Rosetta 下启动和线上登录响应验证安装包中的应用，检查包内 API 地址及资源；Windows 包进行结构和校验验证。Windows 真机安装与业务扫码仍需实机验证。
- 暂未接入自动更新；升级时从首页重新下载。普通卸载不主动清除本机账号资料。

## 工单进线统计（0.1.3）

工单在网站会员后台创建，使用现有登录码分组选择平台账号，再复制公开统计链接。客户端负责同步 WhatsApp、LINE、Telegram 已加载的个人入站消息元数据，Cloud API 使用服务端已接收消息；客户端不新增工单制作入口。

同步不上传消息正文或媒体，不主动拉取平台历史。服务端按账号和客户在工单时间范围内的首次入站消息计数，重复消息 / 重复上报不重复计数。WhatsApp 可用的 LID / 手机号关联用于合并同一客户，避免解析出手机号后重计。尚未同步或未由平台加载的旧历史不会补成完整统计。

本机采用加密持久队列，收到服务端确认后才移除；账号关闭再打开复用同一队列，避免未完成请求覆盖新数据。退出等待待保存数据写入。此次不更改登录码、计费或客户资料。

收集器与队列单元测试、网站工单端到端测试及实际 Electron 沙箱至本机 API 的完整同步链路通过，包含延迟确认期间关闭再打开账号。第三方平台数据采用受控夹具；真实业务账号进线仍需实机接入验证。两个 Mac 包实际启动及生产 API 响应验证通过，Windows 验证范围仍为包结构和校验。

## 记住登录码与登录动效（0.1.5）

登录页默认勾选「记住登录码」，成功登录后将该码通过 Electron 系统加密保存到本机 `login-preferences.json`，下次出现登录页时自动填入。该文件只保存最近一次成功登录的码，按服务地址隔离，不含明文登录码；错误输入不会覆盖保存值。取消勾选会立即删除已记住的密文，并保存取消状态，不必再提交登录。

主动退出客户端后仍可使用已记住的码再次登录，输入新的有效码后替换旧码；原有会话自动恢复逻辑保留。无法解密时提示手动输入，不删除原文件；无法加密时不会退回明文保存，登录成功后提示未能记住。平台页面不能调用读取登录码的 IPC。

按钮点击后显示转圈和扫光动效、锁定表单，失败恢复可点击状态；前端和主进程都阻止重复提交，系统减少动态效果时关闭持续动画。实际 Electron 已验证重启 / 切换 / 取消记住、密文保存、失败重试和原有离线恢复流程，界面仍完整放在小登录窗口内。
