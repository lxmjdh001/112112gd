客户端外壳采用轻量 TypeScript + DOM，仅包含登录、账号切换和状态。此前候选方案中外壳使用 Vue 3，此次为避免两个 UI 运行时并存而简化；中后台仍使用 Vue 3，官方聊天界面不重做。

## 翻译行为

当前使用 Google 无密钥网页翻译接口，已实际获得译文。它不是签约的 Google Cloud Translation API，不能承诺免费额度、可用性或长期兼容性。提供者独立封装，后续可接官方 API。

只有员工主动选中或输入的文字会提交给 Google，经所属账号的代理发送。管理服务不接收消息原文或译文。每次最多 4000 字符，每账号每分钟最多 20 个未命中缓存的请求，12 秒超时；缓存仅在内存中保留 5 分钟、最多 100 项。错误不会覆盖原文，也不会自动发送。复制后由员工粘贴并确认发送。

## 授权与状态

网站登录、客户端授权和 WhatsApp 登录是三个独立状态。后台授权失效时关闭原生页面，保留本机平台登录资料；不会为了连接故障清空 Cookie 或重新创建 WhatsApp 登录。

客户端每 30 秒更新授权心跳，最长离线租约为 150 秒，以单调时钟计时。在线客户端在下一次心跳发现停用或重置后关闭平台页面。重启后必须重新向管理服务验证，不直接信任磁盘中的会话。

网页状态按有限的 DOM 证据分类：加载中、等待扫码、页面就绪、网络异常、待确认。超过 90 秒没有有效观测时网站标为状态过期。“页面就绪”不代表具体消息送达。当前未采集真实平台手机号或联系人身份，所以网站展示的是已分配账号位，尚不是完整的平台账号资料同步。

## 已完成验证

- Go 集成测试：并发设备额度、同机重登、旧令牌替换、重置撤销、到期拒绝、跨租户拒绝、客户端令牌不能访问后台、代理导入原子性、账号额度、分配范围和代理密文往返。

- 管理网站：实际管理员登录、创建长期码、代理错误行提示、10 个模块路由；无浏览器脚本错误。
- macOS arm64 Electron：登录码进入工作台，认证 HTTP 代理打开真实 WhatsApp 官方二维码，翻译浮层正常显示，通过该代理访问 Google 得到中文译文，两个会话分区 Cookie 隔离，后台停用登录码后原生页面关闭。
- 管理网站和客户端 TypeScript 检查、构建通过。自动化验收使用独立测试 schema，没有污染本机使用数据库。
