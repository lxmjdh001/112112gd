# 当前电脑的本地部署

源码目录：`/Users/7c/Documents/web/工单`。

在源码目录执行：

```sh
python3 scripts/local.py start
python3 scripts/local.py status
python3 scripts/local.py stop
```

`start` 启动本地 PostgreSQL、Go API、管理网站与 Electron 客户端。
关闭客户端窗口后，可用 `python3 scripts/local.py desktop` 重新打开。
`stop` 停止本启动器管理的进程及本地数据库，保留数据。

- 管理后台：<http://127.0.0.1:5777>
- API 健康检查：<http://127.0.0.1:18080/healthz>
- PostgreSQL：`127.0.0.1:55437`
- 管理员账号及随机密码：`~/.local/share/gongdan007/admin-access.txt`
- 数据库及密钥配置：`~/.local/share/gongdan007/`，请一起备份。
- 客户端本机资料：源码目录的 `.runtime/desktop-profile/`
- 运行日志：源码目录的 `.runtime/api.log`、`.runtime/admin.log`、`.runtime/desktop.log`

本次为 Apple Silicon macOS 本地部署，使用已有 Node 24 和 Go 1.25，
PostgreSQL 17 的独立二进制保存在 `.runtime/postgres/`。
通过 `GONGDAN_PG_BIN` 和 `GONGDAN_LOCAL_DATA` 可以指定其他数据库程序与数据目录。
运行文件和凭据不提交到 Git。

后续修改客户端后，运行 `pnpm build:desktop`，再关闭并重新打开客户端。
管理网站使用已构建的本地预览版本，修改后台代码后运行 `pnpm build:admin` 并刷新。
Go 服务在启动时检查源码更新时间，必要时重新编译。

本地服务使用新数据库。WhatsApp、Telegram、LINE 的真实登录，以及代理、
翻译服务和 Meta 回调，需要相应账号、网络或外部服务另行配置。
本次不生成正式签名安装包。
