# 产品与技术边界

决定日期为 2026 年 10 月 9 日。

## 已确认产品决定

1. 新建独立的 gongdan007 项目，分阶段实施。
2. 网站集中管理业务，使用者使用桌面客户端。
3. 客户端使用长期登录码，在有效期内可重复登录；后台可限制设备数、重置和停用。
4. 客户端直接加载平台官方 Web 聊天界面，首个平台为 WhatsApp。
5. 中后台采用成熟框架，排除 Ant Design Pro。

## 本计划的技术选择

中后台选用 Vue Vben Admin 的 Element Plus 版本，网站 API 使用 Go 与 Gin，客户端使用 Electron 管理独立浏览器会话。该技术组合服务于官方网页接入与多账号管理。

网站采用租户、管理员、使用者席位、登录码、设备和平台账号分别建模。登录码重置不改变使用者席位的业务身份。平台账号状态与设备在线状态分别展示。

## 需要通过实验确定的能力

官方网页内的账号信息识别、平台连接状态、聊天与联系人采集范围，以及代理故障时各类流量是否保持指定出口，在 P1 验证。页面可正常聊天不自动代表完整历史归档可用。

## 后续业务参数

支付通道、佣金比例、提现规则、钱包监控含义及默认商业额度在对应业务阶段确定。客户端按最新要求持久保持登录，管理服务失联时自动重连，登录码及设备的后台撤销仍保留。

平台账号仅在客户端添加、登录；后台不预创建账号位。网站账号列表展示客户端同步的数据与状态，平台身份提取作为后续能力，不把添加或页面加载当作平台登录成功。
