# gongdan007 阶段验收清单

本轮进度详见 [0.1.0 开发记录](开发进度.md)。原清单中跨操作系统、真实手机账号和多个业务模块的验收项，部分实现时仍保留未勾选。

以下为计划验收项，复选框仅在对应功能已实现并验证后勾选。模拟数据与真实平台测试分别记录，结果附版本、环境与证据。

## P0 项目规划

- [x] 创建独立的 gongdan007 目录。
- [x] 明确网站管理与客户端原生平台网页的边界。
- [x] 记录长期登录码、有效期、设备上限、重置与停用规则。
- [x] 选择 Vue Vben Admin 的 Element Plus 版本作为中后台基础。
- [x] 保存模块、架构、交付阶段与参考图。

## P1 WhatsApp 原生登录验证

- [ ] Windows 和 macOS 客户端加载真实 WhatsApp 官方登录页。
- [ ] 手机扫码后进入官方会话界面，二维码更新由官方网页处理。
- [ ] 重启客户端保留原平台会话，异常时显示可理解的原因。
- [ ] 两个账号使用独立会话；登录、退出或清理一个账号不影响另一个。
- [ ] 绑定代理在首次导航前生效；HTTP、WebSocket、媒体和 DNS 相关行为有验证记录。
- [ ] 错误代理、失效代理、断网时不静默切换直连；WebRTC 行为符合所声明支持范围。
- [ ] 平台退出与客户端失联显示为不同状态；无法识别时显示未知。
- [ ] 形成身份、状态、联系人、实时消息、历史、媒体的能力表。
- [ ] 记录连续运行与本机资源数据，明确实际测试账号数和机器配置。

## P2 网站与权限基础

- [ ] 运营和客户管理员可登录网站，路由和按钮按权限显示。
- [x] 接口权限独立校验，直接请求接口不能绕过页面权限。
- [ ] 两个租户的登录码、设备、代理、客户、线索、导出及统计互不可见。
- [ ] 数据库从空库可完整迁移，应用显示服务版本和环境。
- [ ] 统一搜索、分页、空状态、加载失败、错误提示和表格密度。
- [x] 未实现功能清楚标记，不把模拟统计作为真实数据。

## P3 登录码与设备

- [ ] 单个和批量创建长期登录码，创建结果可分发，列表只展示必要信息。
- [x] 同一码在有效期内可重复使用，同一安装实例重登不重复占名额。
- [x] 多个设备同时验证不能突破设备上限。
- [ ] 后台停用、到期、重置后，服务端立即拒绝旧权限；在线客户端执行撤销并回执。
- [ ] 离线客户端在租约到期后暂停工作，不通过重启获得额外离线授权。
- [ ] 重置不删除席位和业务归属；重新授权后同机本地配置可以找回。
- [ ] 日志不含完整登录码、令牌、Cookie 或代理密码。

## P4 账号和代理管理

- [ ] 员工真实登录的平台账号出现在网站账号列表，并显示正确归属。
- [ ] 身份获取失败、连接状态未知、状态过期分别有准确展示。
- [x] 代理按行批量导入，支持常见 URL 和主机端口凭据格式，错误行单独展示。
- [ ] 重复导入和部分失败重试不造成重复代理资产。
- [ ] 每代理每平台账号上限在并发绑定下仍有效。
- [ ] 客户端检测与服务器检测分开显示来源、时间和结果。
- [ ] 代理切换关闭原连接，新页面及其子资源使用新出口。
- [ ] 账号注销、配置更新等后台指令显示已下发和已执行的区别。

## P5 底库线索客户基础

- [ ] 导入预览、字段映射、失败行下载、批次历史和重复导入均可用。
- [ ] 当前席位、指定席位、全租户含底库的查重范围准确，跨租户无泄漏。
- [ ] PN 与 LID 只有在存在可信映射时才合并，不按姓名合并。
- [ ] 线索可分配、备注、打标签、变更状态并转为客户。
- [ ] 客户资料、跟进记录、标签统计与操作者权限一致。
- [ ] 分享链接只暴露指定字段和记录，支持到期、撤销、访问审计。

## P6 归档与规则监控

- [ ] 真实消息按采集能力范围归档；消息来源、时间及完整性可查。
- [ ] 断网期间本地排队，恢复后补传；相同事件不重复产生客户或消息。
- [ ] 历史未同步区间清楚显示，检索不假定全部历史已归档。
- [ ] 敏感词和其他已定义规则产生可定位告警，支持误报处理和规则停用。
- [ ] 钱包规则的业务定义已确认，规则样例与预期结果一致。
- [ ] 平台网页升级导致采集异常时可关闭采集，继续使用官方聊天页面。

## P7 账户与推广

- [ ] 充值订单、审核或支付回调、账本及余额形成可对账记录。
- [ ] 相同回调或审核请求不会重复入账，退款使用可追踪反向流水。
- [ ] 套餐、设备额度和平台额度购买或到期后正确更新。
- [ ] 字符和 Token 等计量单位清楚区分，重试事件不会重复扣费。
- [ ] 推广关系、有效订单和佣金记录可追溯；比例和归因规则由配置决定。
- [ ] 转余额、提现申请、审核及支付结果分别记录，不从测试产生实际资金交易。

## P8 发布和恢复

- [ ] Windows、Mac Apple 芯片和 Mac Intel 安装包分别构建及验证。
- [ ] 升级保留账号会话与配置，旧客户端与接口版本不兼容时提示明确。
- [ ] 发布产物与 Git 提交、依赖锁文件、迁移版本及校验值对应。
- [ ] 从干净机器取得远端源码能构建，从数据备份能恢复网站业务。
- [ ] 断网、休眠唤醒、代理故障和后台中断后恢复路径有验证记录。
- [ ] 完成 24 至 72 小时真实账号稳定性测试，记录未覆盖的功能及容量范围。

## 验收记录格式

每次验收记录阶段、版本、提交号、系统与机器配置、测试账号数量、前置条件、实际结果、证据位置、已知缺口及是否通过。真实账号的号码、代理密码、登录二维码与令牌不得出现在公开报告中。
