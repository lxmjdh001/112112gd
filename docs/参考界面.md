# gongdan007 参考界面

本地保存了用户提供的 11 张参考截图，用于菜单与业务字段对照。截图中的示例数据、其他系统的商业规则和平台支持列表不直接成为本项目默认配置。原始图片仅保存在本机参考目录，已从 Git 跟踪中排除。

| 文件 | 对应范围 | 本项目处理 |
| --- | --- | --- |
| [导航](references/01-navigation.png) | 首页、邀请码列表、账号列表 | 首页入口统一称工作台，客户端凭据统一称登录码 |
| [平台账号](references/02-platform-accounts.png) | 平台过滤与账号信息表 | 首版只开放 WhatsApp，其他平台按实际接入开放 |
| [账户中心](references/03-account-center.png) | 资料、充值、记录和计量 | 全部纳入账户模块，账本与计量单位明确区分 |
| [推广中心](references/04-promotion.png) | 推广步骤与佣金说明 | 推广归因、佣金及提现规则做成可配置业务规则 |
| [登录日志菜单](references/05-login-log-menu.png) | 系统菜单 | 登录日志独立入口 |
| [登录日志列表](references/06-login-logs.png) | IP、浏览器设备、时间 | 增加网站与客户端来源、结果和失败原因 |
| [代理列表](references/07-proxies.png) | 分组、导入、导出、批量操作 | 代理资产与平台账号绑定分别保存 |
| [代理表单](references/08-proxy-form.png) | 协议、凭据、分组、平台限额 | 支持批量识别和每平台绑定上限，密码默认掩码 |
| [底库](references/09-contact-baseline.png) | 联系人来源与去重范围 | 底库按租户隔离，号码和平台内部 ID 分开处理 |
| [线索](references/10-leads.png) | 席位统计、分组与工单分享 | 席位统计与线索明细分开视图，分享支持范围和撤销 |
| [客户运营](references/11-customer-operations.png) | 客户管理与内控 | 资料、标签、跟进先做；归档与监控依赖数据采集验证 |

客户端聊天区域直接采用平台官方 Web 页面。上述截图用于网站中后台和客户端外围操作的需求参考，不据此重画 WhatsApp 聊天界面。
