# 账号指纹配置

创建账号时先选择当前电脑网络或独立代理，然后在「指纹配置」中使用当前电脑、手动修改参数或点击「随机生成」。修改任意参数自动切换到自定义；「使用当前电脑」清除未提交的自定义设置。点击「添加并登录」统一保存并应用，无需再点一次应用按钮。

自定义配置包括操作系统标识、GPU 厂商与型号、User-Agent、屏幕分辨率、时区、语言、CPU 核心数、内存以及 WebRTC。高级选项提供 Canvas、音频、WebGL 噪声和禁止本地字体加载。内存遵循浏览器可报告范围，8 GB 表示 8 GB 及以上。

随机生成使用匹配的系统、GPU 和 Chromium 标识组合，独立生成账号噪声种子，保留使用者选定的时区与语言。只在点击时生成，不会在刷新、打开账号或重启时重新随机。时区和语言由用户选择，不自动声称与代理出口所在地匹配。

迁移 020 在 `platform_accounts` 添加 `browser_fingerprint`，原有账号为 NULL，继续使用本机配置。创建与打开接口按团队、登录码及设备权限处理，校验参数；同一创建请求重试不得更换指纹。后台与客户端需一同升级。当前只提供创建时配置，不修改既有账号的指纹。

客户端在加载平台页面前设置账号自己的 User-Agent 和请求语言，通过 Chromium DevTools Protocol 应用 UA Client Hints、操作系统标识、时区、语言、CPU 和屏幕参数；在平台页面脚本运行前设置 GPU、内存和可选噪声。完全禁用 WebRTC 会阻止页面建立 PeerConnection，默认继续禁止非代理 UDP。指纹配置失败或调试连接意外断开会关闭对应视图并提示重新打开，保留登录资料，避免悄悄回退到其他配置。

这是每个账号网页的浏览器配置，不改变真实硬件、浏览器内核或 IP。GPU 文本不会改变实际渲染驱动；Canvas/WebGL/音频保护针对已适配页面 API，不承诺覆盖所有 Worker、OffscreenCanvas、字体测量或平台检测方式。本地字体选项限制 CSS 本地字体渲染，并拦截 JavaScript 通过 FontFace 加载本地来源，并非虚构安装字体列表。操作系统、GPU、语言等应结合实际需要设置。

## 验证

- `pnpm --filter @gongdan/desktop typecheck`、`pnpm test:desktop`、`pnpm build:desktop`。
- `node scripts/check-fingerprints.mjs`：隔离会话验证手动/随机/还原 UI、无效参数、页面首个脚本读到的值、HTTP 请求头、Client Hints、稳定噪声、字体加载、本机配置互不影响及重启恢复。
- `NATIVE_FINGERPRINT_CHECK=1 LINE_COMPONENT_ARCHIVE=/path/to/verified.crx node scripts/check-native-platforms.mjs`：在自定义配置下检查 Telegram 账号隔离与真实 LINE 登录页。
- Go 的 `TestAccountFingerprintPersistenceValidationAndRetry` 和全量服务端测试：实际 PostgreSQL 下验证保存/读取、幂等、参数校验、跨登录码隔离以及迁移。

界面和运行时测试使用隔离数据，不登录真实平台账号、不发送客户消息。


## 浏览器版本边界（0.1.4）

当前客户端内核仍为 Electron 44.7.0 / Chromium 152.0.7977.130。随机生成始终使用实际内核版本，不继承手填的旧 User-Agent。新建时，界面、主进程和服务端均限制 Chrome 主版本为 120–152；客户端还按实际运行的内核限制上限，拒绝混入 Electron、HeadlessChrome 或其他浏览器产品标识。

120 是产品兼容性下限，不代表平台承诺所有版本永远可用。以后升级 Electron 时同步更新服务端上限及共享常量。打开已保存账号时，超出兼容范围的 Chrome 版本在运行时修正为实际内核，其他指纹参数、固定种子、Cookie 和登录资料保留；不批量修改数据库里的账号配置。默认 User-Agent 也移除应用显示名称压缩后生成的产品标识，避免网站误判浏览器种类。

新增测试覆盖过低 / 过高版本拒绝、手动低版本后随机重置、既有低版本账号重新打开时修正、HTTP / Client Hints 一致和原固定噪声保留。
